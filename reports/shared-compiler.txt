Shared compiler rewrite (2026-10-17)

Scope
The complete PR uses the ordinary Fusor tensor/compiler path.
There is no ExecutionProfile, gpu_inference constructor, Apple adapter preset,
model-specific schedule pin, or alternate Llama decode implementation.
The only model-source change is adopting the shared immutable GGUF byte storage
interface; graph construction, sampling, and device selection match main.

Compiler changes
- Recognize normalization from Map/Fold/View algebra. Retain the logical graph
  for differentiation and price the fused launch during normal extraction.
- Recognize single-query attention from QK, stable softmax, and PV contractions,
  including grouped heads and prefix masks. Width comes from the operands;
  fixed subgroup width and resource limits determine legality. Unsupported
  cases retain the existing algebraic implementation.
- Coalesced Q4/Q6 loads are selected from format, layout and subgroup legality.
  Whole-block storage views preserve buffer bytes and checked accesses.
- Forward affine views and pure map slabs through the ordinary compiler.
  Forwarding validates each extracted plan, and rekeys the previous selection
  after rejected graph unions. Replanning preserves the exact rejection cause.
- Lower contiguous range updates into ordinary WebGPU copy/clear commands.
- Keep symbolic single-index scatter geometry in uniforms; growth changes the
  dispatch grid without compiling another shader.
- Keep full-size and expanding views in the producer's replay plan. Only
  partial views materialize their base separately. View forwarding preserves
  the reduction's index space; equal element counts alone are not sufficient.

Runtime changes
- Generic QMatrix and dense-layer GGUF loaders share immutable host bytes,
  as does the model loader. Concatenation retains segments without copying
  every weight into another full host allocation.
- Bounded prepared-plan/artifact caches apply to normal resolves.
- One compiler worker by default avoids retaining a cohort of lowered kernels.
- Submission overlaps preparation within the existing in-flight resource bound.
- Production replay keeps its incumbent by default. Explicit online tuning is
  still available, but no longer substitutes an alternative every 16 resolves.
  Previously measured winners remain reusable with online exploration disabled.
- Cache-only donation and its alias-specific lowering have been removed.
  Ordinary scatter preserves its input and retained views. Prepared GPU
  artifacts share the normal plan's weak ownership; no alternate plan is needed.

Validation
- All seven ordinary-device WebGPU tests pass with compiler-tests and
  kernel-observer enabled (13.88 seconds). Cases cover RMS/attention vs host
  references, copy lowering, concrete/symbolic/expanding view replay, scatter
  input and retained-view preservation, view reductions plus gradients, and
  softmax Jacobian-vector products with replay.
- Q4/Q6 outputs match dequantized references at N=1024/1027, K=4096, and
  one/three input rows. Aligned cases select both coalesced lowerings without
  a preset; odd dimensions may select another legal schedule.
- Symbolic grouped attention crosses 256 keys, grows storage to 512 slots,
  and remains correct through 260 keys with zero extra shader compilations.
- All 14 candidate-construction tests pass. Normalization tests cover four
  shapes and absent/16/32/64-wide subgroups. Attention tests cover five channel
  widths, grouped heads, and concrete/symbolic keys. Unsupported cases decline.
- Both prepared-plan and GPU-artifact ownership tests pass.
- The model library and both visualization/profiling examples pass cargo check.
- The portable Python tool suite passes all 11 tests. Tests and stubs for
  removed historical controllers were removed with those controllers.
- All 29 visualizer Rust tests pass after the relocated-archive CLI fix.
- The packed-word verifier and persisted-schedule/pipeline-reuse tests pass.
- The complete Fusor workspace/all-target Clippy check passes with warnings
  denied and kernel-observer enabled; formatting and diff whitespace pass.

Resource validation
Checks used one compiler job and one GPU process, at least 12 GiB starting
memory headroom, a 1 GiB process-group RSS cap, no additional swapouts, a 32 MiB
compressor-growth ceiling, and a 1 GiB runtime disk reserve. Small incremental
tests may start with that disk reserve plus a 64 MiB linking allowance; larger
checks require 1.5 GiB at startup. No model was loaded for these checks.
The final GPU suite peaked at 0.387 GiB process-group RSS, with at least
13.535 GiB memory headroom and no added swapouts.

An expanded fixture initially exceeded its process-group cap while retaining
multiple matrix graphs. It now releases the graph, device and GPU pool between
cases and completes inside the same cap. When another workload reduced free
disk below the reserve, builds were refused. They resumed after space recovered;
only obsolete task-owned executables and check metadata were removed.

CI follow-up
Cross-platform compilation, Clippy, and WebGPU compilation passed at 4cb376d55.
The subsequent native conformance results caught a reduction/view addressing
bug and two gaps in the kernel type verifier (half-word unpack and signed
shifts). A small verified WebGPU test reproduced the addressing panic before
its fix; all seven verified GPU regressions now pass.

A softmax-backward case additionally exposed a cyclic forwarded selection.
The compiler now validates that candidate and restores the incumbent using
its current class identities. The reproducer checks three row geometries and
replays the resulting gradient; it matches the host Jacobian-vector product.

The visualizer CLI tests now use runtime paths when Nextest relocates an
archive. The cooperative scratch assertion follows the shared fragment
geometry, and persisted measured schedules remain usable when online tuning
is disabled. CI is being rerun for these corrections. An unrelated macOS
root test failed when archive.org returned HTTP 500; a Windows GPU shard lost
its WARP device. Neither is counted as a pass.

    --features kernel-observer,compiler-tests --config profile.dev.opt-level=0 --config profile.dev.debug=0 --test shared_compiler -- --ignored --test-threads=1


Performance scope

part of the PR. Their earlier 2x result does not establish throughput for this
rewrite. A fresh full-model comparison remains unverified: the final read-only
preflight refused 14.96 GiB headroom against its 15.17 GiB requirement. No model
was started. The previously
built release chat executable also predates this rewrite.
